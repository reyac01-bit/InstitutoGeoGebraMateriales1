# Capítulo 10, actividad 1 - El rectángulo que se desarma
# Pegar línea por línea en la barra de entrada (GeoGebra Classic 6, español).
# Lo que va en comentario (#) se aplica a mano en Configuración del objeto.
# Comandos ejecutados en GeoGebra Classic por la API el 10-nov-2026 (véase LEEME.txt).
# Lo que va en comentario (#) se configura a mano y no formó parte de esa prueba.

# Figura izquierda: dibujo (cuatro puntos libres)
A = (0, 0)
B = (4, 0)
C = (4, 2.5)
D = (0, 2.5)
dib = Polígono(A, B, C, D)

# Figura derecha: construcción (dependencias)
E = (6, 0)
F = (10, 0)
rEF = Recta(E, F)
pE = Perpendicular(E, rEF)
pF = Perpendicular(F, rEF)
G = Punto(pF)
rG = Recta(G, rEF)
H = Interseca(rG, pE)
con = Polígono(E, F, G, H)
# Ocultar rEF, pE, pF, rG (o dejarlas en gris claro, estilo punteado).
# Mover G a una posición inicial sobre pF, por ejemplo (10, 2.5).

# Estado y medidas condicionadas
est_medir = false
# Insertar casilla de control vinculada a est_medir, leyenda "Mostrar medidas".
angDib = ÁngulosInteriores(dib)
angCon = ÁngulosInteriores(con)
esq1 = Esquina(1)
txtDib = Si(est_medir, Texto("Izquierda: ¿siguen siendo rectos?", esq1 + (0.4, 0.6)))
# GeoGebra nombra los ángulos angDib_1 ... angDib_4 y angCon_1 ... angCon_4
# (ÁngulosInteriores no crea una lista; corregido el 10-nov-2026).
# Condición para mostrar el objeto (pestaña Avanzado) de esos ocho ángulos:  est_medir
# Marcar esq1 como auxiliar.
rectDib = SonPerpendiculares(Recta(A, B), Recta(B, C)) && SonPerpendiculares(Recta(B, C), Recta(C, D)) && SonPerpendiculares(Recta(C, D), Recta(D, A))
# Color dinámico del polígono dib (relleno):
#   Rojo:  Si(rectDib, 0.1, 0.8)
#   Verde: Si(rectDib, 0.6, 0.2)

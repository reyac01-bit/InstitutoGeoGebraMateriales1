# Ejemplo 4 - Convolución como área móvil
f(x) = Si(x >= 0, exp(-x), 0)
g(x) = Si(0 <= x <= 2, 1, 0)
t = Deslizador(0, 10, 0.1, 1, 220, false, true, false, false)
h(x) = f(x) g(t - x)
A = Integral(h, 0, t)
P = (t, A)                         # activar Rastro
conv = Secuencia((s, Integral(f(x) g(s - x), 0, s)), s, 0, 10, 0.25)
curva = Poligonal(conv)
txtA = Texto("Área = " + A, (6.5, 1.4))
# Vista CAS (parte simbólica):
#   F := Laplace(exp(-t), t)
#   G := Laplace(Si(0 <= t <= 2, 1), t)
#   Factoriza(F * G)
#   LaplaceInversa(F * G, s)
# Correcciones del 10-nov-2026: f y g llevan el caso contrario (0); sin él, Integral(h, 0, t)
# quedaba indefinida. En la secuencia, Integral va con tres argumentos: con (expr, x, 0, s)
# GeoGebra calculaba IntegralEntre(expr, x, 0, s), el área entre la curva y la recta y = x.
